# Livrables Windows 1.2.6

Télécharger `Timox.VASIO.Control.Setup.1.2.6.exe` depuis la [release 1.2.6](https://github.com/timox/TimoxVasio/releases/tag/v1.2.6). Accepter la demande d'administration Windows : le Setup installe Control, le moteur et le pilote ASIO. Relancer les applications audio déjà ouvertes pour qu'elles chargent la nouvelle DLL.

La version portable `Timox.VASIO.Control.1.2.6.exe` n'installe pas le pilote. `TimoxVasio.Driver.1.2.6.zip` permet une installation manuelle. `MANIFEST.json` contient le commit source et les empreintes SHA-256.

Voir les [notes de version](RELEASE_NOTES_v1.2.6.md) et le [guide d'installation](INSTALL.md).
