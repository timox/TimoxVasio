# Livrables Windows 1.2.3

Télécharger les quatre fichiers de la [release 1.2.3](https://github.com/timox/TimoxVasio/releases/tag/v1.2.3) : `TimoxVasio.Driver.1.2.3.zip`, `Timox.VASIO.Control.Setup.1.2.3.exe`, `Timox.VASIO.Control.1.2.3.exe` et `MANIFEST.json`.

Extraire le ZIP, puis exécuter `Installer TimoxVasio.bat` en administrateur. Il enregistre la DLL sous `C:\Program Files\Steinberg\VirtualASIO\1.2.3`. Relancer les applications audio ouvertes avec une ancienne DLL. Installer ou lancer ensuite Control : son interface et son moteur sont empaquetés ensemble.

Le manifeste donne le commit source et les empreintes SHA-256. Voir les [notes de version](RELEASE_NOTES_v1.2.3.md) et le [guide d'installation](INSTALL.md).
