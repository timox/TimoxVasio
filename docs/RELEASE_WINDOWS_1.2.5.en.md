# Windows downloads 1.2.5

Download `Timox.VASIO.Control.Setup.1.2.5.exe` from [release 1.2.5](https://github.com/timox/TimoxVasio/releases/tag/v1.2.5). Run it and accept the Windows administrator prompt: Setup installs Control, the engine, and the ASIO driver. Then restart Renoise, Mixxx, or other audio applications that were already open so they load the new DLL.

The portable `Timox.VASIO.Control.1.2.5.exe` does not install the driver. `TimoxVasio.Driver.1.2.5.zip` supports manual installation if needed. `MANIFEST.json` records the source commit and SHA-256 hashes.

See the [release notes](RELEASE_NOTES_v1.2.5.en.md) and [installation guide](INSTALL.en.md).
