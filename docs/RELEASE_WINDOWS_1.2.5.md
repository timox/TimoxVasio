# Livrables Windows 1.2.5

Télécharger `Timox.VASIO.Control.Setup.1.2.5.exe` depuis la [release 1.2.5](https://github.com/timox/TimoxVasio/releases/tag/v1.2.5). Le lancer et accepter la demande d'administration Windows : le Setup installe Control, le moteur et le pilote ASIO. Relancer ensuite Renoise, Mixxx ou les autres applications audio déjà ouvertes pour qu'elles chargent la nouvelle DLL.

La version portable `Timox.VASIO.Control.1.2.5.exe` ne procède à aucune installation du pilote. `TimoxVasio.Driver.1.2.5.zip` permet une installation manuelle si nécessaire. `MANIFEST.json` contient le commit source et les empreintes SHA-256.

Voir les [notes de version](RELEASE_NOTES_v1.2.5.md) et le [guide d'installation](INSTALL.md).
